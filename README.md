# موقع سورة البقرة — نور القرآن

صفحة عربية ثابتة لقراءة سورة البقرة والاستماع إليها، مع عرض التفسير الميسر لكل آية.

## ملفات المشروع
- `index.html`: واجهة الموقع ومنطق تحميل النص والتفسير والتلاوات.
- `SOURCES.md`: مصادر النص والتفسير والتلاوات وملاحظات الحقوق.
- `PREPUBLISH-CHECKLIST.md`: اختبارات القبول المطلوبة قبل الإعلان العام.

## الوظائف الحالية
- تحميل نص `quran-uthmani` لسورة البقرة من AlQuran Cloud.
- تحميل إصدار `ar.muyassar` من التفسير الميسر وربط المدخل بالآية عبر `numberInSurah`.
- فحص آلي أولي يرفض عرض النص أو التفسير إذا لم يكن عدد الآيات 286 أو لم يكن الترقيم متسلسلاً.
- عرض قائمة القراء المتاحين لسورة البقرة من MP3Quran.
- لا يُفعّل تشغيل الآية منفردة أو تكرارها إلا إذا وجد فهرس توقيتات للقراءة واكتملت توقيتات الآيات 1–286.
- تشغيل السورة كاملة وفتح رابط MP3 من خادم المصدر.

## تنبيه مهم حول «مصحف المدينة»
النسخة الحالية تعرض نصاً عثمانياً إلكترونياً برواية حفص؛ ولا تعرض صورة صفحات مصحف المدينة أو تخطيطه الطباعي أو خطوطه الرسمية. يلزم اعتماد خط/صور صفحات مرخّصة ومراجعة شكلية إذا كان المطلوب مطابقة صفحات المصحف المطبوعة.

## التشغيل محلياً
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. لا توجد عملية بناء أو قاعدة بيانات. يعتمد الموقع على خدمات خارجية، ولذلك قد تتأثر الوظائف بتوفرها وسياسات CORS ومعدلات الطلب.

## قبل الإطلاق العام
لا تعتبر وجود زر أو رابط دليلاً على عمله. نفّذ قائمة الاختبارات في `PREPUBLISH-CHECKLIST.md`، خصوصاً:
1. مطابقة 286 آية وتفسيراً مع مصدر موثوق، مع تدقيق بشري لعينة من الآيات.
2. اختبار كل قارئ مختار ورابط ملف سورة البقرة فعلياً.
3. اختبار حدود توقيت الآيات وإعادة المقطع والتكرار.
4. تثبيت الإسناد والحصول على تأكيد حقوق التسجيلات والتفسير عند الحاجة.
5. اختبار الهاتف والحاسوب، وإظهار رسائل مفهومة عند تعطل المصادر الخارجية.

**حالة التحقق:** لم يتسنّ في جلسة المراجعة إجراء طلبات شبكة مباشرة إلى واجهات AlQuran Cloud أو MP3Quran أو اختبار ملفات الصوت من المتصفح. لذلك لا تُعد وظائف البيانات والصوت مختبرة حياً بعد.
