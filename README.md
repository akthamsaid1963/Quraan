# المصحف الواضح — سورة البقرة

هذا المستودع يحتوي على صفحة الموقع في `index.html`.

## تشغيل محلي
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. يعتمد تحميل النص وقائمة القراء على واجهات خارجية، لذلك قد تتأثر الخدمة بتوفر تلك الواجهات وسياسات CORS.

## النشر عبر GitHub Pages
1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)`.
4. احفظ الإعدادات وانتظر اكتمال النشر. سيظهر رابط الموقع في صفحة Pages.

## قبل النشر العام
- راجع النص العثماني على مصحف معتمد.
- تحقق من مطابقة التفسير الميسر لكل آية ومصدره وحقوق إعادة استخدامه.
- اختبر روابط التلاوات، وتوفر سورة البقرة في كل رواية، وأذونات تنزيل ملفات MP3.
- اختبر الموقع على الهاتف والحاسوب، وأضف معالجة واضحة لأخطاء الخدمات الخارجية.
- لا تعتبر وجود مشغل صوت دليلاً على عمل التوقف/الإعادة عند حدود كل آية؛ يلزم اختبار ذلك على تسجيلات ذات توقيتات موثوقة.

## ملاحظة
إضافة هذا الملف لا تعني أن الموقع نُشر بالفعل. يتطلب النشر تفعيل GitHub Pages من إعدادات المستودع.
